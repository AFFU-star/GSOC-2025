# Contributing to Plone Foundation - GSoC 2025

Welcome to Plone Foundation's Google Summer of Code (GSoC) project! This guide will help you understand how to participate and submit a successful proposal.

## Prerequisites
Before applying:
- Familiarize yourself with Plone CMS
- Set up a development environment following our [documentation](https://docs.plone.org/develop/index.html)
- Make at least one contribution to Plone (can be documentation, bug fix, or feature)
- Join our community channels (see Communication Methods below)

## How to Submit a Proposal
Your proposal should include:
1. Personal Information
   - Name
   - Contact details
   - Time zone
   - GitHub username
   - Resume/CV

2. Project Information
   - Project title
   - Project description
   - Timeline with milestones
   - Expected outcomes
   - How your skills match the project requirements

3. Prior Experience
   - Programming experience
   - Open source contributions
   - Relevant coursework or projects

## Communication Methods
- Community Forum: https://community.plone.org
- Gitter Chat: https://gitter.im/plone/public
- Weekly Development Meetings (schedule will be provided)

## Selection Process
1. Initial screening of proposals
2. Interview with potential mentors
3. Final selection based on proposal quality and interaction with community

## Project Ideas
View our current project ideas list at [GSoC 2025 Projects](link-to-your-projects-list)

## Need Help?
- For general questions: Use the community forum
- For project-specific questions: Contact potential mentors
- For technical issues: Create a GitHub issue

Remember: Quality over quantity. We value well-thought-out proposals that show understanding of the project and enthusiasm for open source!
